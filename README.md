# Домашнее задание №5 - Интернет-магазин

Это веб-приложение интернет-магазина, разработанное в рамках домашнего задания для КТС. Приложение реализует полнофункциональный интернет-магазин с каталогом товаров, корзиной покупок, системой авторизации и адаптивным дизайном.

## 🌐 Продакшн версия

**Демо**: [https://your-deployed-app.vercel.app](https://your-deployed-app.vercel.app)
> *Замените ссылку на актуальный URL после деплоя*

## ✨ Функциональность

- 📦 **Каталог товаров** - просмотр товаров с фильтрацией и поиском
- 🛒 **Корзина покупок** - добавление/удаление товаров, расчет стоимости
- 👤 **Система авторизации** - регистрация и вход в аккаунт
- 📱 **Адаптивный дизайн** - поддержка мобильных устройств
- 🔍 **Поиск и фильтры** - поиск по названию и фильтрация по категориям
- 📄 **Пагинация** - разбиение списка товаров на страницы
- 🎨 **Современный UI** - стильный интерфейс с использованием SCSS модулей

## 🛠 Технологии

### Frontend
- **Next.js 15.5.4** - React фреймворк с App Router
- **React 19.1.0** - UI библиотека
- **TypeScript 5** - типизированный JavaScript
- **MobX 6.15.0** - управление состоянием
- **SCSS** - препроцессор CSS с модульным подходом
- **Turbopack** - сборщик для быстрой разработки

### Дополнительные библиотеки
- **classnames** - утилита для работы с CSS классами
- **qs** - парсинг query параметров
- **mobx-react-lite** - интеграция MobX с React

### Инструменты разработки
- **ESLint** - линтер кода
- **Sass** - компилятор SCSS

## 🚀 Установка и запуск

### Требования
- Node.js 18+ 
- npm, yarn, pnpm или bun

### Установка зависимостей
```bash
npm install
# или
yarn install
# или
pnpm install
```

### Запуск в режиме разработки
```bash
npm run dev
# или
yarn dev
# или
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере для просмотра приложения.

### Сборка для продакшн
```bash
npm run build
# запуск продакшн версии
npm start
```

### Линтинг кода
```bash
npm run lint
```

## 📁 Структура проекта

```
app/
├── (main)/              # Основные страницы приложения
│   ├── products/        # Каталог товаров
│   ├── product/[id]/    # Страница отдельного товара
│   ├── basket/          # Корзина покупок
│   ├── categories/      # Категории товаров
│   └── about_us/        # О нас
├── login/              # Страница входа
├── register/           # Страница регистрации
└── shared/             # Переиспользуемые компоненты и утилиты
    ├── api/            # API клиенты (Strapi)
    ├── components/     # UI компоненты
    ├── store/          # MobX stores
    ├── hooks/          # React хуки
    ├── styles/         # Глобальные стили
    └── utils/          # Утилитарные функции
```

## 🎨 Основные компоненты

- **Button** - кнопки различных типов
- **Input** - поля ввода с валидацией
- **Card** - карточки товаров
- **Header** - шапка сайта с навигацией
- **MultiDropdown** - выпадающий список с множественным выбором
- **PageSelector** - пагинация
- **ImageSlider** - слайдер изображений
- **Loader** - индикатор загрузки

## 📊 Управление состоянием

Приложение использует **MobX** для управления состоянием:
- `ProductsStore` - каталог товаров
- `CartStore` - корзина покупок  
- `CategoriesStore` - категории товаров
- `RootStore` - корневой стор

## 🔧 API Integration

Приложение интегрируется с **Strapi CMS** через REST API:
- Получение списка товаров
- Управление корзиной
- Авторизация пользователей

## 📱 Адаптивность

Приложение адаптировано для различных устройств:
- Десктоп (1200px+)
- Планшет (768px - 1199px)
- Мобильный (до 767px)

## 🔗 Маршруты

- `/` - главная страница (перенаправление на `/products`)
- `/products` - каталог товаров
- `/product/[id]` - страница товара
- `/basket` - корзина покупок
- `/categories` - категории
- `/login` - вход в аккаунт
- `/register` - регистрация
- `/about_us` - о нас
